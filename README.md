# YouTube Playlist Importer

First-stage Obsidian desktop plugin for importing a YouTube playlist.

## Features

- Command palette command: `YouTube Playlist Importer: Import YouTube playlist`
- Playlist URL validation
- Folder mode: one Markdown note per video
- Single-note mode: one raw YouTube link per video
- Metadata frontmatter
- Duplicate avoidance
- `yt-dlp` integration

## Requirements

- Desktop Obsidian
- `yt-dlp` installed and available in PATH, or its full executable path configured in plugin settings

## BRAT

Push the contents of the repository root to GitHub. BRAT needs `manifest.json`, `main.js`, and `styles.css` in the repository root or in a GitHub release.
